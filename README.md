# visuals

Visuales audio reactivos hechos en TouchDesigner.

## Estructura

| Carpeta | Contenido |
| --- | --- |
| `project/` | Archivo `.toe` que carga el resto del proyecto |
| `scripts/build/` | Scripts que arman la red de operadores |
| `scripts/audio/` | Análisis de audio: FFT, bandas y beat |
| `scripts/ext/` | Extensions de componentes |
| `shaders/lib/` | Funciones GLSL compartidas |
| `shaders/scenes/` | Un shader por visual |
| `presets/` | Parámetros por escena en JSON |
| `assets/audio/` | Pistas de prueba locales (no versionadas) |
| `renders/` | Capturas y exports (no versionados) |
| `docs/` | Notas del proyecto |
